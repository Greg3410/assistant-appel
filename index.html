Test micro pendant l'appel

Ce test vérifie si Chrome peut entendre votre interlocuteur pendant un appel normal, en haut-parleur. Aucune donnée n'est enregistrée.

Mode d'emploi

  1. Avant l'appel, lancez le test A et parlez : la barre doit bouger.
  2. Appelez quelqu'un avec l'application Téléphone et mettez le haut-parleur.
  3. Revenez sur Chrome (sans raccrocher), demandez à la personne de parler, puis lancez le test A, puis le test B.
  4. Envoyez-moi une capture d'écran du résultat.
